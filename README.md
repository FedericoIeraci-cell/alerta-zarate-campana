# Proyecto retirado

Alerta Zárate–Campana se retiró el 28 de octubre de 2026 por decisión del titular, para concentrar el trabajo exclusivamente en el TP académico de Goya, Corrientes.

La aplicación muestra únicamente un aviso de retiro. Se eliminaron de la rama principal los workflows de actualización y publicación de ZC. No se consultan datos ni se emiten avisos desde esta aplicación.

El código y los datos históricos permanecen en Git como respaldo. Su conservación no acredita operación, vigencia ni vigilancia. La supervisión de ChatGPT para ALA/ZC también fue desactivada.
